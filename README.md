# In Waiting: Concept

A gameplay concept for **In Waiting**, a card-haggle game about a servant secretly scheming to win her mistress a crown, one waltz at a time.

**This is a non-commercial concept for internal team review. It uses copyrighted images and other people's work as placeholders. None of that work belongs to this project, and all of it will be replaced with original art before any release.** All rights stay with the original creators. If you own any of this work and want it removed, please open an issue.

## Run it

Open `webapp/` through any static web server, or run:

```bash
python3 webapp/serve.py
```

Then go to http://localhost:8642.

## What's here

- `webapp/`: the playable concept of the Ball
- `GAME_PLAN.md`: the full game design
- `prototype/`: an early terminal version of the rules. It still plays an older version of the Ball
